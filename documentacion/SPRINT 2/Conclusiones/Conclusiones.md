# Conclusiones

El desarrollo e implementación de la plataforma para el Jardín Infantil Semillero en Ibagué demuestra que las herramientas digitales son canales efectivos para promover y consolidar hábitos de alimentación saludable en niños de edad preescolar.
El uso de arquitectura C4 y el registro de decisiones técnicas mediante documentos ADR permitieron establecer una estructura de software clara, escalable y debidamente documentada para futuras expansiones.
La integración de Next.js, React y Tailwind CSS dio como resultado una interfaz de usuario ágil y adaptativa, lo que permite facilitar la gestión educativa del Jardín Infantil Semillero de la ciudad de Ibagué.

# Identificación de Stakeholders y Usuarios Finales

## Stakeholders
Los stakeholders son todas las partes interesadas en el proyecto que pueden afectar o ser afectadas por el mismo.

## Usuarios Finales
Los usuarios finales son las personas que utilizarán directamente la aplicación web para promover hábitos alimenticios saludables.

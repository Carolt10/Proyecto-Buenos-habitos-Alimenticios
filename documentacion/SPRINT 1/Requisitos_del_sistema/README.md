# Requisitos del Sistema

## Requisitos Funcionales
Los requisitos del sistema constituyen la base fundamental para el desarrollo del software debido a que definen qué debe hacer la plataforma y bajo que criterios se debe trabajar; el objetivo de los requerimientos del sistema toma las necesidades detectadas y las convierten en funcionalidades técnicas.

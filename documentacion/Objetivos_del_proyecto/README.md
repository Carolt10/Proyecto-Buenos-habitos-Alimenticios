# Objetivos del proyecto

## Objetivo general
Desarrollar un sitio web interactivo que contenga información y material para generar conciencia a los padres de los niños del Jardín Semillero de Ibagué con respecto a los hábitos alimenticios con el propósito de disminuir notablemente el consumo de productos azucarados.

## Objetivos especificos
- Impactar de manera positiva para disminuir el consumo de azúcar en los niños.
- Desarrollar un sitio web que sea fácil de usar, que cumpla con los criterios establecidos en la documentación y sea desplegado correctamente.
- Definir un mapa de Stakeholders y matriz de riesgos relacionados al proyecto.

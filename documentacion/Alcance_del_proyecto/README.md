# Alcance del Proyecto

Este documento describe el alcance de nuestro proyecto sobre hábitos alimenticios saludables.

## Objetivo
El objetivo principal de este proyecto es promover hábitos alimenticios que mejoren la salud y el bienestar.

## Alcance
El alcance del proyecto incluye:
- Investigación sobre diferentes técnicas de alimentación saludable.
- Desarrollo de materiales educativos.
- Implementación de talleres y actividades de sensibilización.
- Evaluación del impacto de las intervenciones.

## Entregables
Los entregables del proyecto son:
- Manuales de buenas prácticas alimenticias.
- Informes de evaluación y mejora.
- Talleres en comunidades.

## Limites Del Proyecto
Este proyecto no incluye:
- Consultas médicas.
- Planificación dietética personalizada más allá de los materiales educativos.
